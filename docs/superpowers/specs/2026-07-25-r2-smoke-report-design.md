# R2 카드 데이터 스모크 테스트 HTML 보고서 설계

## 목적

Blizzard Hearthstone Game Data API에서 수집한 실제 카드 샘플이 raw·정제 데이터와 이미지 asset으로 변환되고 Cloudflare R2에서 다시 검증된 결과를 한 화면에서 설명한다.

이 보고서는 제품 UI가 아니라 개발 검증용 독립 산출물이다. `src/`, `src-tauri/`와 런타임 계약은 수정하지 않는다.

## 산출물

- 경로: `preview/r2-card-data-smoke-report.html`
- 형식: 외부 UI 라이브러리가 없는 단일 HTML/CSS/JavaScript 파일
- 데이터 방식: 검증 당시의 결과와 카드 요약은 HTML에 고정하고, 이미지와 원본·정제 JSON 링크는 실제 공개 R2 URL을 사용한다.
- 기본 언어: 한국어

## 정보 구조

### 1. 요약 머리말

- 데이터 버전 `r2-smoke-20260725T021319Z`
- 최종 상태 `공개 재검증 통과`
- 공식 API, Cloudflare R2와 GitHub 저장소 링크

### 2. 핵심 검증 지표

- R2 객체 40개
- manifest 대상 asset 39개
- 이미지 33개
- 한국어·영어 카드 레코드 각 15개
- 공개 재다운로드 SHA-256 오류 0건
- 황금 이미지 0개

### 3. 데이터 흐름

다음 순서를 짧은 단계형 흐름으로 표현한다.

```text
Blizzard OAuth API
→ raw 응답 보존
→ 앱용 정제
→ 이미지 SHA-256 중복 제거
→ R2 업로드
→ 공개 URL 전수 재다운로드 검증
```

### 4. 대표 카드

세 메인 카드를 일반 이미지와 함께 보여준다.

- 온천 활공꾼 / Hot Spring Glider
- 불카노스 / Vulcanos
- 흉물의 의례 / Rite of Atrocity

각 카드에는 비용·공격력·생명력, 키워드 ID, 효과 텍스트와 공식 `childIds` 개수를 표시한다.

### 5. 관련 카드 증거

- 온천 활공꾼: 관련 카드 0장
- 불카노스: 관련 카드 2장
- 흉물의 의례: 관련 카드 10장

관련 카드는 수집 가능 여부와 카드 타입을 함께 표시해 일반 수집 카드가 아닌 개체도 raw와 정제 데이터에 들어왔음을 보여준다.

### 6. raw와 정제본 비교

대표 필드 변환을 표로 비교한다.

| raw | 정제 |
| --- | --- |
| `classId`, `multiClassIds` | `class_ids[]` |
| HTML 포함 `text` | `effect.markup`, `effect.plain` |
| `childIds` 누락 가능 | 항상 배열인 `relations.child_ids[]` |
| 공식 이미지 URL | URL과 실제 바이트 SHA-256 |
| `imageGold` | 배포 제외, `gold: null` |

### 7. 배포 asset과 링크

- 공개 manifest
- 한국어·영어 raw JSON
- 한국어·영어 정제 카드 JSON
- 한국어·영어 정제 메타데이터 JSON
- 공개 GitHub 저장소

## 시각 방향

- 기존 프리뷰와 어울리는 짙은 흑연색 배경과 따뜻한 금색 강조색을 사용한다.
- 검증 성공은 녹색 한 종류로 제한하고 장식보다 근거 수치와 링크를 우선한다.
- 카드 이미지를 제외한 장식 이미지는 추가하지 않는다.
- 1280px 데스크톱을 기본으로 하되 760px 이하에서는 단일 열로 재배치한다.
- 표와 링크는 키보드로 접근할 수 있고, 텍스트 대비를 충분히 확보한다.

## 오류와 제약 표현

- 보고서는 검증 완료 시점의 스냅샷이며 실시간 모니터가 아님을 명시한다.
- 공개 이미지가 불러와지지 않으면 카드 이름이 포함된 대체 영역을 표시한다.
- GitHub Secrets가 아직 등록되지 않았고 테스트 자격증명은 로컬 Git 무시 파일에만 있음을 표시한다.
- 로컬의 다른 미커밋 작업은 보고서 대상이나 수정 범위에 포함하지 않는다.

## 검증 기준

- 로컬 파일을 브라우저에서 직접 열 수 있다.
- 핵심 수치가 manifest 및 공개 재검증 결과와 일치한다.
- 세 카드 이미지가 공개 R2에서 표시된다.
- raw·정제·manifest·GitHub 링크가 올바른 목적지를 가리킨다.
- 1280px와 760px 이하에서 내용이 겹치거나 잘리지 않는다.
- 콘솔에 보고서 자체 JavaScript 오류가 없다.
